# 本地部署目录说明

- `deploy/redis/redis.conf`：Redis 服务配置文件
- `deploy/elasticsearch/`：Elasticsearch 配置和 JVM 堆参数覆盖文件
- `deploy/nginx/`：iBoot 与 JetLinks 的 Nginx 站点配置
- `deploy/iboot/config/application-prod.yml`：iBoot 外部生产配置
- `deploy/jetlinks/config/application-prod.yml`：JetLinks 外部生产配置
- `deploy/runtime/`：运行期数据、日志、上传文件和 JetLinks 前端静态资源
- `deploy/OPERATIONS.md`：部署结果、配置详情、验证命令和运维命令说明
